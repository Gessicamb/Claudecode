# Story 1.1: Set Up IDE Code Debug MCP Integration

**Epic:** Developer Tooling Setup
**Story ID:** 1.1
**Status:** Done
**Type:** Infrastructure
**Priority:** High
**Points:** 2

---

## User Story

As a developer working on Claudecode,
I want the ide-code-debug MCP server configured in Claude Code,
So that I can use debugger tools (breakpoints, variable inspection, call stack) directly from Claude Code during development sessions.

---

## Objective

Register the `ide-code-debug` VS Code extension as an MCP server in the project's `.mcp.json`. This enables Claude Code to call debugger tools exposed by the extension over HTTP on `localhost:3100`, providing breakpoint management, step execution, variable inspection, and call stack analysis.
