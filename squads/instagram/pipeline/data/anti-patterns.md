# Anti-Patterns — Instagram Content

## Content Anti-Patterns

| Anti-Pattern | Why It Fails | Fix |
|-------------|-------------|-----|
| "Follow for more tips" as CTA | Overused, low trust | "Save this for later" or "Tag someone who needs this" |
| Headline-only slides | No value, feels lazy | Always include 40-80 words of supporting text |
| Generic hook: "In today's post..." | Zero scroll-stopping power | Start with a bold claim or surprising fact |
| Cramming 15+ insights into one post | Information overload | Max 1 key insight per slide |
| All same background color | Visual fatigue after slide 2 | Alternate light/dark/accent backgrounds |
| Caption that starts with "Hey guys!" | Generic, loses attention | Start with your strongest line |
| 30 hashtags with no relevance | Spam signal to algorithm | 8-15 highly relevant tags only |
| Ending without any CTA | Missed engagement opportunity | Always end with a specific, low-friction ask |

## Publishing Anti-Patterns

| Anti-Pattern | Consequence | Fix |
|-------------|------------|-----|
| Publishing without credentials set | Script fails publicly | Test with `--dry-run` first |
| Wrong image order | Carousel tells wrong story | Confirm order in Publisher step |
| Caption over 2200 chars | API error, publish fails | Validate before publishing |
| PNG images | API rejects non-JPEG | Convert to JPEG before adding to output/images/ |
| Less than 2 images | Carousel requires minimum 2 | Add at least 2 images |

## Strategic Anti-Patterns

| Anti-Pattern | Long-term Impact |
|-------------|-----------------|
| Posting without research | Misaligned hashtags, irrelevant angles |
| Skipping review checkpoint | Publishing errors that can't be undone |
| Same content type every post | Audience fatigue, algorithm deprioritization |
| Ignoring engagement in first 30 min | Reduced distribution |
