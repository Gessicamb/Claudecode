# Domain Framework — Instagram Content Production

## Carousel Architecture (8-10 slides)

| Slide | Role | Goal |
|-------|------|------|
| 1 | Hook | Stop the scroll — bold claim or curiosity gap |
| 2-3 | Problem/Context | Establish why this matters |
| 4-7 | Body/Value | Core educational or inspirational content |
| 8-9 | Summary/Key Takeaway | Consolidate the value |
| 10 | CTA | Drive the desired action |

## Slide Content Formula
Each body slide = **Headline + Supporting Text**
- Headline: 5-10 words, bold claim or key insight
- Supporting text: 40-80 words, evidence, example, or elaboration
- Alternate background colors for visual rhythm

## Hook Formulas
1. **Number-based**: "7 things X that Y" (clear promise)
2. **Contrarian**: "Stop doing X" (challenges assumption)
3. **If/Then**: "If you're doing X, read this" (specific audience)
4. **Curiosity gap**: "The real reason X happens" (withholds info)
5. **Direct benefit**: "How to X in Y" (clear outcome)

## Caption Formula
```
[Hook line — max 125 chars]

[Body — 2-3 short paragraphs expanding the topic]

[Hashtags — 8-15 relevant tags]

[CTA — one specific, low-friction action]
```

## Production Checklist
- [ ] Hook stops scroll (first slide)
- [ ] Every slide has headline + supporting text (40-80 words)
- [ ] Visual rhythm: alternating backgrounds
- [ ] Caption first line works standalone
- [ ] 8-15 hashtags
- [ ] CTA is specific
- [ ] Images in correct order
