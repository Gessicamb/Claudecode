# Quality Criteria — Instagram Content

## Carousel Quality (Score each 1-5)

| Criterion | 1 (Poor) | 3 (Acceptable) | 5 (Excellent) |
|-----------|----------|----------------|---------------|
| Hook strength | Generic, forgettable | Clear topic | Stops scroll, creates urgency |
| Slide completeness | Headline only | Headline + thin text | Headline + 40-80 word supporting text |
| Value density | Vague, filler | Some actionable points | Every slide delivers a distinct insight |
| Visual flow | No rhythm | Some variation | Alternating colors, consistent template |
| CTA | Missing | Generic ("follow us") | Specific, low-friction ("Save this") |

**Minimum acceptable score: 3.5 average**

## Caption Quality

| Criterion | Pass | Fail |
|-----------|------|------|
| First 125 chars | Self-contained hook | Requires clicking "more" to understand |
| Length | 300-1200 chars | Under 50 or over 2200 |
| Hashtags | 8-15 relevant | 0-5 or 16-30 |
| CTA present | Yes, specific | No or too generic |

## Technical Validation

- [ ] Caption ≤ 2200 characters
- [ ] Hashtags ≤ 30
- [ ] Images: JPEG only
- [ ] Image count: 2-10 for carousel
- [ ] `.env` credentials configured

## Acceptance Threshold
Content is approved when:
- Carousel scores ≥ 3.5 average
- All caption criteria pass
- All technical checks pass
- User explicitly approves in Step 03
